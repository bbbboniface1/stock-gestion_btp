1) SAISIE DE LA QUANTITÉ
Fichier : artifacts/stock-pwa/src/pages/invoice-new.tsx
- La quantité d'une ligne de facture est forcée à un minimum de 1 via
  `Math.max(1, Math.floor(Number(e.target.value) || 1))` (~ligne 302)
  et la validation ligne ~99 rejette tout `quantity < 1`.
- Corrige pour que l'utilisateur puisse taper directement un chiffre au
  clavier (ex: effacer le champ et taper "12") sans que la valeur soit
  reset à 1 pendant la saisie, et sans être obligé de passer par les
  flèches d'incrémentation du input number.
- Autorise 0 comme valeur transitoire pendant la saisie, mais bloque la
  soumission du formulaire si une ligne a quantity <= 0 (validation à
  la soumission, pas à chaque frappe).
- Vérifie aussi le composant Input utilisé (probablement un simple
  <Input type="number">) : gère le cas où le champ est vidé (chaîne
  vide) sans forcer immédiatement une valeur.

2) PDF FACTURE : DÉBORDEMENT SUR DESCRIPTION LONGUE
Fichier : artifacts/api-server/src/routes/invoices.ts (route GET
/invoices/:id/pdf, généré avec pdfkit)
- Actuellement chaque ligne a une hauteur fixe (rowH = 22) et la
  description est dessinée avec { width: 255, ellipsis: true }, ce qui
  tronque le texte au lieu de le faire passer à la ligne, et décale/
  chevauche les colonnes QTÉ / PRIX UNIT. / TOTAL quand le texte est
  long.
- Corrige en :
  a. Calculant dynamiquement la hauteur nécessaire pour la description
     AVANT de dessiner la ligne (pdfkit expose doc.heightOfString(text,
     { width }) pour ça), avec retour à la ligne (pas d'ellipsis, ou
     ellipsis seulement au-delà d'un nombre max de lignes, ex: 3).
  b. Utilisant cette hauteur calculée comme rowH pour cette ligne
     spécifique (au lieu du 22 fixe), pour positionner correctement
     la quantité, le prix unitaire et le total sur la même ligne,
     verticalement centrés ou alignés en haut.
  c. Vérifiant que checkPageSpace / addNewPage prennent bien en compte
     cette hauteur variable pour ne pas couper une ligne entre deux
     pages.
